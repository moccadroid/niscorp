# Haptic qualification — 4 November 2026

The approved ownership and verification corrections are implemented. The architecture is cleaner and several concrete defects are fixed. **Broad automatic discovery has not reached the requested nine-out-of-ten standard.** The frozen batch, later diagnostic correction and focused XML rerun are separate evidence versions.

## What changed and why

1. **One Prism owner across all formats.** XML source authors now propose XPath only. Mechanical selection supplies actual `{url,items}` to the published Prism `mappingAgent`, using the same reference-proposal job as native JSON. JSON assembles and jointly trials the selection/mapping before allowing traversal. A failed pair can correct upstream selection; budgets and job histories remain shared and bounded. The composite XML/Prism author and duplicate schema are deleted.
2. **Local XML work instead of interleaved orchestration.** The paired correction has one cohesive JSON helper. Mechanical source trials consume named local inputs instead of another whole state object. Seven normal frozen/current helper comparisons preserve their outputs. This removes an ownership exception; it is not a claim that model accuracy automatically improves.
3. **Reviewer inspections retain fitting evidence.** Inspecting one paragraph previously replaced Ruby's full page, incorrectly discrediting two correct links. Review now retains the fitting prepared page once plus scoped query/field/range facts, within the existing combined allowance. Oversized pages retain bounded views. Source-author context and all limits are unchanged.
4. **Resource/integrity failures stop at their owner.** Existing XML byte/node/depth/selection ceilings and corrupt-body checks now use `RunControl`, like the other resource controls. The same codes, messages and JSON-profile limits remain. Bad XPath stays repairable; corrupt captures and exhausted resource controls cannot become ordinary retry feedback. No engine change or error-code policy layer was added.
5. **Repair receives the actual missing path.** The trial adapter discarded Prism's operation/path and artifact boundary paths. It now preserves those available strings alongside the existing code/message, excluding arbitrary details and causes. Existing JSON feedback carries them under existing byte limits. This is an error-boundary correction, not another model or repair system.
6. **Tests check meanings and cardinality.** An independent review exposed a grader that could accept a headline and description swapped within a record. The benchmark now requires explicit evaluator field roles and cardinality declarations; ambiguous layouts are unscorable. Negative controls cover wrong associations, duplicates, unrelated results, metadata and grouped context. These are test declarations, never caller approval or a new discovery step.

All eleven engine files, connector files, model adapter, model settings and dependency lock remain unchanged against the pre-slice freeze. Native changes implement mechanics and diagnostics. JSON still owns workflow, prompts, branches, repair and numeric limits. No dependency, database, controller, browser or site-specific production policy was added.

Ordinary HTTP proves that the real ZIP is named in a static CSV comment already visible to the model; element-text extraction cannot express reading that comment. No browser is inherently required, and no site-specific decoder was added.

- Four original attempts remain unresolved: Lua mapping recovery, Lua connection timeout, GitHub mapping allowance and Django linked-post mapping recovery. Spiegel's additional attempt fails bounded provider quota retries.
- Source/traversal and root repair still impose significant cross-flow cognitive load. This is maintainability debt, not a reason for a universal controller or database.
