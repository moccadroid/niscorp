# Job-specific discovery

Status: approved narrow replacement for the failed universal-controller experiment. This specifies the current fixed pipeline. Implementation/review/model measurements are reported separately; this document makes no accuracy or performance claim.

## Objective and boundary

An unchanged request plus URL, optional schema and explicit permissions produces a reusable mechanical artifact or a concrete unresolved result. No manual approval is part of that contract.

Finished execution remains **JSON artifact → prepared in-memory engine → result data**. No execution AI, credentials, database, persistence service, native planner or alternate crawler is introduced. Prism owns conversions/programs; Strata owns grammar stamps. Fields remain dynamic.

## Fixed JSON pipeline

1. Admit request/profile and compile any caller schema before effects.
2. Declare only `{requiresNavigation,resultFlow}`. JSON checks caller ceilings/offered actions and bounds admission retries.
3. Acquire/traverse using existing HTTP, aliases, BFS and resource helpers. Offer complete admitted frontiers within their context allowance.
4. Author one current HTML/XML source component. The only alternatives are format-specific source inspection or `{action:"propose",candidate:...}`. JSON executes mechanical trials and commits success automatically. Identified mechanical failures narrow the component, preserving unrelated rule data.
5. Assemble the actual complete captured extraction. Standalone JSON remains native; XML supplies selected values. Reference tasks use existing source/reference/resource contracts.
6. Preserve the caller schema or author an ordinary schema after grounding. Invalid declarations receive compilation feedback; an admitted schema is fixed for later mapping.
7. Author bare Prism against actual native input and that schema. Mechanical failures receive bounded feedback to the same mapping job, without source restart or schema revision.
8. Obtain a verdict-only semantic review of actual shaped data against matching source evidence. Negative feedback can repeat the same fixed author pipeline within the configured repair bound and remaining allowances, retaining each job's own history.
9. Fresh URL-artifact mechanical verification determines publication. Return the working artifact as `ready` with its separate review verdict even when negative. An invalid correction retains the preceding working candidate and its matching schema/verdict; fresh mechanical failure remains terminal.

JSON owns calls, branches, prompts, thresholds and budgets. TypeScript offers strict schemas and generic mechanics. No model chooses a phase, routes an arbitrary component edit or authors an intermediate prompt for another agent.

| Output program                                          | Bare published ConfigSchema; standalone owner-derived Prism profile headed OUTPUT SCHEMA |

Source queries never acquire arbitrary URLs. They cannot offer finish, component/value inspection, schema revision or publication. Cortex retains its existing envelope/schema recovery and emit protocol. Native code schedules no semantic retries and runs no hidden validator/trial callbacks.

The default remains configured 120b with high reasoning, temperature 1, top-p 1 and emit. JSON profile values own all settings. Task/source/schema/mapping work shares one author step/time allowance per attempt; per-response recovery is bounded by its remainder. Review calls share the current attempt's reviewer allowance with Cortex recovery. `review.maxRepairs` bounds fixed-pipeline repeats, each with fresh configured author and reviewer allowances. Page/resource charges, permissions, caller schemas and the whole-run engine/cancellation ceiling remain unchanged across attempts. Actual provider retries/waits remain transport evidence.

## Retained mechanics and deletions

Retain source-preserving preparation, original-format evidence, current native parsers/selectors, static binding, complete captured trials, resource accounting, the final data guard and fresh mechanical verification. Preserve original captures, failed trials, credentials and Git history.

Delete the universal phase/focus controller, finish actions, component/value inspection, cross-agent/full-source conversation replay and superseded profile fields/helpers/aliases. The subsequently authorized review-feedback repeat keeps only own-job proposals/observations/review messages, and may reauthor a generated schema while preserving caller schemas. Do not retain a public strategy switch for the failed design.

The public request, finished `{url}` input and `{data,visited,limited,redirects}` output remain. Download bytes/metadata stay outside data. Discovery's reason/partialTrial expose failure without certifying diagnostic output. Review remains fallible; semantic completeness and arbitrary future reuse are not guaranteed.

## Falsifiable checks

- Caller schemas are unchanged and malformed contracts fail before HTTP/models. False/zero permissions and allowances cannot be increased by model output.
- HTML/XML source contracts reject retired finish/component/value actions. Known selector/field errors become mechanical feedback; cancellation/integrity/resource controls stay terminal.
- Source inspection accesses only offered current-frontier captures. Display windows preserve complete extraction; cleared HTML payloads and original bytes do not leak into model context.
- Actual Cortex wire shows bare Prism documentation and preserves the strict full grammar/recovery. No response-grammar wrapper is nested around programs.
- Mechanical component correction preserves unrelated rules and charged acquisition state. Budgets cannot reset at phase changes or retries.
- Automatic schema declaration follows grounded extraction, compiles before mapping and remains fixed afterward. Caller and generated contracts do not become new user restrictions.
- A semantic rejection supplies bounded author feedback and remains visible independently of artifact availability. Working artifacts survive negative verdicts and invalid corrections. Fresh-trial failure is terminal.
- Actual search composition reaches these same flows, passes the original instruction/time/ceilings and consumes the completed discovery trial without duplicate execution.
- Returned artifacts execute changed values/links/records and permitted empties without AI. Report those checks separately from same-source replay.
- Compare focused model outcomes, provider requests/tokens/waits, discovery time and mechanical execution separately. Retain failures and unavailable usage; never infer accuracy from schema validity or review grades.
