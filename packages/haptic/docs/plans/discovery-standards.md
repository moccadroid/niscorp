# Discovery consolidation and review checkpoints

The whole-library review found sound execution boundaries but avoidable complexity in discovery. This work corrects those ownership problems without changing the fixed author pipeline, model settings, prompts, permissions, source formats or artifact execution grammar.

## Acceptance criteria

1. One owned model configuration reaches every model operation, including search ranking and rewriting. Provider failures with unavailable usage cannot report measured zero.
2. One host-supplied mechanical capability registry serves acquisition, preparation and trials. Host resources remain host-owned. Existing plain HTTP stays the default; no browser/dependency is added.
3. The public discovery result has a strict, explicit contract. A ready result carries a working artifact/schema/fresh completed trial; unresolved carries a concrete reason. Captures, prepared documents, model transcripts and private stage state are excluded. Useful partial data and advisory negative review remain available.
4. Original response bytes have one private acquisition owner. Level/owned views carry URL/hash identities, and prepared documents have one owner. Missing or stale identities fail explicitly. Redirect-only alias evidence remains available to captured trials. Existing source/trial recording preserves diagnostic evidence before compaction.
5. Budget/settings/error calculations have one JSON definition. Fixed phases are cohesive documents with explicit handoffs; splitting alone is insufficient. No universal controller, native planner or replacement DSL is introduced.
6. Each field-reading helper requires its consumed paths; each value-producing helper validates its produced shape. Open outer state views preserve unrelated context intentionally, while phase-owned values are closed. Successful and failed phase outputs cannot both accept malformed success. A giant repeated global state schema is excluded.
7. Model-result envelopes and public output are validated independently of fallible semantic review. Existing schemas and partial-result rules do not become new completeness gates.
8. Current status has one owner in documentation. Dated captures/reports remain history, never a newer accuracy claim.

## Verification

Freeze prior source/tests and use existing real provider/source captures. Verify model configuration/permissions/cancellation/history/charges, exact settings equivalence, canonical source ownership and compact public results offline. Malformed phase-required values must fail before model/HTTP work, malformed producer values before the next consumer, and source mutations/aliases/empty results must retain existing semantics. Run full offline/package checks and the HTTP-only PDF regression after integration. No paid model/prompt experiment is part of this cleanup.

Checkpoint one is the integrated ownership/contracts change: the retained reviewers inspect producers through consumers, especially data duplication and adapter consistency. Fix modest findings directly. A further review is justified for material boundary revisions, not every edit. The final checkpoint grades the entire current system again after regression checks and documentation; grades are independent judgments, not assertions manufactured from test counts.

Engineering cleanliness and semantic discovery accuracy remain separate. This refactor must preserve useful outputs and remove avoidable defects; it cannot turn an old accuracy measurement into a new one or guarantee complete results from arbitrary websites.
