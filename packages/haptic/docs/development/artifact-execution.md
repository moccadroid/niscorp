# Artifact execution and discovery

**JSON artifact → prepared in-memory engine → result data.** Finished execution has no models, credentials, database or implicit persistence. Strata owns grammar stamps; Prism owns transformations. Preparation admits contracts/programs once; repeated execution reads current values and links mechanically.

## Ownership

| Owner             | Responsibility                                                                                   |
| ----------------- | ------------------------------------------------------------------------------------------------ |
| Request           | URL, unchanged instruction, optional reference time/schema and explicit page/resource ceilings   |
| Discovery JSON    | Fixed phase order, prompts, model settings, mechanical feedback/retries, budgets and publication |
| Mechanical JSON   | HTTP/redirect/BFS/resource composition, static binding and declared checks                       |
| Native operations | Typed model calls, bounded transport/readers/selectors/XPath/HTML views and trials               |
| Finished artifact | Learned rules, fixed result schema, Prism program and resolved policy                            |

The engine interprets admitted JSON; it does not plan discovery. Profiles cannot add unsupported native capabilities. Link depth, interpreter call depth, JSON depth and parser depth are different bounds.

## Fixed construction path

Admit → bounded task declaration → acquire/traverse → source candidate/trial → complete captured extraction → schema if needed → bare Prism/trial → final verdict → fresh mechanical trial → publication.

HTML/XML source calls offer only current-frontier source inspection or a component proposal. Mechanical trial success commits automatically. Errors with an identified component can narrow repair; there is no model finish, arbitrary component navigation or full transcript replay. Standalone JSON requires no invented selector stage.

Caller schemas compile before effects and remain unchanged. Otherwise an ordinary schema is authored after extraction and mechanically admitted. Once admitted it stays fixed for that shaping pass; a review-driven repeat may reauthor only an automatic schema. Mapping retries use actual native input and execution/schema feedback under the same author allowance. A negative verdict can trigger the configured bounded repeat of the fixed author pipeline, with each job receiving its own proposal/observation history and the review feedback. Working artifacts are returned independently of that verdict; callers receive the review separately. Fresh complete mechanical verification remains required.

The final reviewer sees actual shaped data separately from its schema and matching source evidence. Its positive verdict still requires the fresh complete artifact run. Failure is terminal. Neither the captured verdict nor passing checks proves fresh semantic correctness or future reuse.

## Source ownership

HTML preparation is replaceable/bypassable JSON policy. It parses using extraction's defaults, clears configured script/style/attribute/SVG payloads on a private DOM, serializes and verifies round-trip integrity/byte bounds. Original captures remain unchanged for extraction/trials. XML stays original until XPath selection; JSON stays native.

Source inspection reads already-owned current-frontier data. Windows bound evidence displays, not full extraction. Oversized subtrees are omitted explicitly rather than chopped into false markup. No inspection can fetch a URL or restore cleared payloads. Byte limits are not token guarantees.

Complete captured trials execute the combined plan against owned responses. Charged acquisition/resources and aliases survive local mechanical retries. The final fresh URL trial is separate transport work under the artifact ceilings; page/resource limits are not one aggregate HTTP-count ceiling spanning all discovery and verification.

## Finished results

Input is `{url}`. Output is `{data,visited,limited,redirects}`, with declared resource bytes/metadata outside data. Visited counts acquired target URLs, including the start. Redirect hops spend no extra target slots; distinct aliases may spend slots before their shared final document is known. That document is fetched/extracted once.

The start is depth zero and followed links increment depth. Empty selections create no result page. Limited means a mechanical allowance stopped work, not semantic incompleteness or completeness. Missing learned stages fail before unlearned acquisition and require discovery/maintenance, never execution AI.

Schemas, preconditions and the fallible final guard cannot catch every wrong/missing result. The saved 7-Zip frozen-version and Steam unrelated-offer failures remain limitations.

Current construction contracts and falsifiable checks are in [job-specific discovery](../plans/job-specific-discovery.md). The required verification remains typecheck, the full offline suite, mechanical live-PDF and package-consumption checks. Those checks are not a fresh-model accuracy result.
