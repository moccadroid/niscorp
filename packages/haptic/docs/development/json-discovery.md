# JSON discovery

The public entry uses the JSON-owned format catalog and shared HTTP acquisition. Exactly one supported adapter must match. Supplied result schemas compile unchanged before effects. Without one, the separate ordinary-schema author runs after grounded extraction.

JSON stays a native value: scalar strings, numbers, booleans, null, arrays and objects preserve their identity. There is no whole-document conversion into HTML, a universal element tree or fixed fields. Reader/transport profiles own byte, nesting, decoding and integrity limits.

Standalone JSON needs no selector author. Its actual `{document,url}` becomes input for the dedicated bare-Prism job, under mechanical `$.input`. The job sees the original instruction, fixed result schema, actual native input and relevant mapping feedback. JSON executes mechanical trials and bounds corrections; the model cannot navigate phases or revise an admitted schema.

Task and schema declarations are separate. Automatic schema admission follows source grounding, and invalid declarations can receive compilation feedback. Once admitted, the schema stays fixed. Generated descriptions cannot weaken the instruction; caller schemas remain unchanged.

One final-data reviewer receives actual shaped data separately from the data schema and matching original native JSON. A negative verdict can trigger the configured bounded repeat of the fixed author pipeline, with each job receiving its own proposal/observation history and the review feedback. Working artifacts are returned independently of that verdict; callers receive the review separately. Fresh complete mechanical verification remains required. Published artifacts accept `{url}` and return `{data,visited,limited,redirects}` without AI or credentials.

Execution reads current JSON and enforces the frozen format/policy. Correct original output does not prove completeness or future reuse. Navigation/resource tasks compose [reference following](reference-following.md); arbitrary terminal JSON data leaves within that traversal and mixed-format frontiers remain unsupported.

See [the builder](discovery-builder.md), [output shaping](output-shaping.md) and the [fixed finish line](remaining-work.md). Discovery is best effort; mechanical verification does not guarantee semantic accuracy. Historical results retain their original scope, and another model experiment is not a first-release gate.
