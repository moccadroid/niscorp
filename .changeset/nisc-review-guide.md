`REVIEW.md`, beside `AGENTS.md`: a guide for an agent reviewing a nisc app, written to be run on its own — how to run a review, the counts that say where an app has drifted, the checklist, what to look for, and how to report by rule number. The checklist is the one `AGENTS.md`'s "Verification" carried; "Verification" now points to it. `AGENTS.md` says near its top to build with it and review with `REVIEW.md`, after each step of the order of work, not only at the end.

**What to change:** nothing. To review an app, point the reviewing agent at `node_modules/@niscorp/nisc/REVIEW.md`.
