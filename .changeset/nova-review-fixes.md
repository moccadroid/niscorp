A name every object inherits (`toString`, `constructor`, `valueOf`) is no longer found as an action, fragment, endpoint, function, phrase, slot or directive; a removeAt or move index template that is no whole number leaves the array alone and the next steps run; a stored layout that comes back to itself renders a clear `RenderError` instead of overflowing the stack. An actions or fragments map keyed by something other than the id is now reported to `onError` (the shell still loads it), and the README lists what each adapter kit ships.
