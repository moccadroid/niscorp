Integrate Haptic: an instruction and a web address become a reusable data artifact that reads current values with no model. Artifacts follow the `nisc.haptic` grammar (HTML, XML and JSON stages, run by the package's runtime); discovery is TypeScript with small checkable model questions (Read through cortex, Jev labels, Prism programs); search ranks DuckDuckGo results and solves its image challenge with Jev. The package stays private pending its first authorized release.
